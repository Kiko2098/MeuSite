Dashboards de Gestão sobre o Primavera

Indicadores do dia a dia lidos diretamente da base de dados do ERP: vendas, pendentes e stock no telemóvel.

  • Python
  • SQL Server
  • Cegid Primavera

Antes

  • Informação de gestão só acessível dentro do ERP
  • Mapas corridos e exportados para Excel
  • Sem visão rápida no telemóvel
  • Pendentes acompanhados com atraso

Depois

  • Vendas, pendentes e stock em tempo real
  • Sem exportações manuais
  • Acessível no telemóvel, no computador e nas TVs
  • Acesso seguro, sem VPN nem portas abertas

Como funciona

  1. 1

    Dados

    Consultas diretas à base de dados do ERP.

  2. 2

    Indicadores

    Vendas por período, cliente e artigo, pendentes e stock.

  3. 3

    Acesso

    Publicado com autenticação e PIN, através de Cloudflare Tunnel.

  4. 4

    Relatórios

    Os mesmos dados alimentam relatórios PDF enviados por email.
