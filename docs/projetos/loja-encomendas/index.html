Loja de Encomendas ligada ao Primavera

Loja online para uso interno de um armazém de distribuição alimentar: cada encomenda entra diretamente no ERP como documento de venda.

  • Python
  • Cegid Primavera
  • Web API

Antes

  • Encomendas registadas fora do sistema de faturação
  • Listas de artigos e preços mantidas à mão
  • Cada encomenda reintroduzida manualmente no ERP
  • Pouco controlo sobre lotes e paletização

Depois

  • Catálogo, preços e clientes sempre iguais aos do ERP
  • Encomendas montadas no terreno, em poucos passos
  • Documento de venda criado automaticamente, pronto a faturar
  • Lotes, embalagens e paletes escolhidos na própria encomenda

Como funciona

  1. 1

    Cliente

    Escolha do cliente, com os dados vindos diretamente do ERP.

  2. 2

    Artigos

    Artigo, lote e quantidade, com apoio a paletização e embalagens.

  3. 3

    Confirmação

    Dados de entrega e observações; a encomenda fica no histórico.

  4. 4

    Faturação

    A encomenda entra no ERP como documento de venda, pronta a ser finalizada.

Destaques

Catálogo sempre atualizado

Artigos, preços e clientes lidos do ERP, sem listas paralelas.

Histórico de pedidos

Cada encomenda guarda o estado, os dados de entrega e as observações.

Gestão de utilizadores

Login próprio, para controlar quem cria e consulta encomendas.

Impressão de documentos

Integrada no fluxo de confirmação da encomenda.
