Heartbeat: remote monitoring

Monitoring of applications installed at clients with no VPN, no open ports and no remote access to the machines.

  • Python
  • Cloudflare Tunnel

Before

  • Silent failures on client machines
  • Problems only known when the client called
  • Monitoring would require a VPN or open ports
  • Alternative: paid third-party solutions

After

  • Each service sends a periodic heartbeat
  • Email alert when something stops responding
  • Dashboard with every client and service
  • No VPN and no open ports on clients' routers

How it works

  1. 1

    Agent

    Each machine periodically sends a heartbeat, always initiated by the client.

  2. 2

    Receiver

    Validates the device and key and records the status of each service.

  3. 3

    Dashboard

    Real-time view of every service, grouped by client.

  4. 4

    Alerts

    Email when a service fails, respecting each service's expected hours.
