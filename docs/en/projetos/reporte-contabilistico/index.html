Accounting Report in PowerPoint

A Primavera extension for an accounting firm that generates each client's financial report in PowerPoint.

  • C#
  • OpenXML
  • Cegid Primavera

Before

  • Monthly report put together by hand
  • Trial balances exported to spreadsheets
  • Values copied into the presentation
  • Transcription errors

After

  • Report generated from the accounting data
  • Indicators calculated automatically
  • Comparison with the same period last year
  • Presentation ready to send, with the firm's branding

How it works

  1. 1

    Company

    Open the client company in Primavera.

  2. 2

    Period

    Choose the year, period and currency.

  3. 3

    Indicators

    Income statement and indicators are calculated.

  4. 4

    PowerPoint

    The .pptx is generated, with no need for PowerPoint to be installed.

Highlights

Income statement indicators

Year-on-year comparison

Each indicator compared with the same period of the previous year.

Four ready-made slides

Cover, executive summary, indicator panel and income statement.

No PowerPoint needed

The file is generated directly (OpenXML), from a template.
