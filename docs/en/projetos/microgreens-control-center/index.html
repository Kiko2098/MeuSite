MicroGreens Control Center

Web application to manage production for a microgreens grower: from planning to deliveries, with per-batch traceability.

  • Python
  • React
  • PostgreSQL
  • Docker

Before

  • Information locked in old Android and desktop versions
  • Hard to follow production from the floor
  • Production disconnected from purchasing, stock and deliveries
  • Transport documents handled separately

After

  • Available on phone, tablet or computer
  • Production orders followed stage by stage
  • Stock, purchasing and deliveries linked to production
  • Transport documents issued and reported to the Tax Authority from the app

Production cycle

  1. 1

    Preparation

    The production order is created from the technical sheet, with the components and times for each stage.

  2. 2

    Germination

    Each order moves through stages, with dates and locations visible in the planning.

  3. 3

    Blackout and exposure

    Operator tasks follow each stage until harvest.

  4. 4

    Delivery

    Labels, delivery to the customer and transport document, without leaving the app.
